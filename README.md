Hi, right now I'm working (complementary to my other activities) on a beta project with AI, the Pixel Art Studio, but it's just an idea; I hope to improve it. It's basically for generating sprites and backgrounds. Since a sprite is an image, the AI should be able to make it; otherwise, since the sprite is a pixel drawing, the AI should handle it like a model. And finally, since a sprite is a set of movements (.gif), e.g., sprite resources, it should be able to 'pixelate' according to a model. Colors are another topic—I wanted to show everything, from Atari, Nintendo<<< up to the N64, that is, 8x8 = 4-color palette (8, 16, 32 on all platforms). That’s why the intention is for the AI to draw, or attempt to draw, on an 8x8 square canvas = 1 square, the sprite = HxW squares or its equivalent in little squares. From there came the initial intention of my project to control everything, but I’m focusing only on NINTENDO. I used two free AIs: Inkling (text and image recognition) and the Pollination (image generator).
It's a basic project, like I mentioned, just BETA and it has a lot of bugs.  
e.g. 1. Dr. Mario sprite ---> replicate pixel photo  
2. sprite or sprite replica + photo + prompt ---> the image fails  
3. model photo + photo + prompt ----> it should vectorize or scale, fails.  
I uploaded it to a repository in case it can be improved.
